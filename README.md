  Создать некоторый маршрут из n = 20 вершин, найти кратчайший путь используя «муравьиный алгоритм», количество итераций it = 300, количество муравьев 2n = 40. 
  
РЕШЕНИЕ:

  Алгоритм был написан на языке программирования Python с использованием библиотеки pygame. Также, был реализован интерактивный пользовательский интерфейс, с визуализацией алгоритма.
  Файл main.py. В нём представлен главный функционал алгоритма./ Файл form.py. Необходим для сбора значений с клавиатуры, таких как: скорость выполнения алгоритма, количества разброса феромона на путях, количества вершин и длин путей.  
  
ИТОГ:

  В ходе работы был реализован алгоритм коммивояжёра на основе муравьиного метода для поиска оптимального маршрута. Алгоритм имитирует природное поведение муравьёв, эффективно находя решения даже в задачах с большим количеством возможных маршрутов. Его основные преимущества — гибкость, адаптивность к изменяющимся условиям и способность избегать застревания в локальных минимумах.
Интуитивно человек может быстро соединить точки и получить приближённое решение, если их мало и они расположены логично. Однако, когда число точек увеличивается или их расположение становится хаотичным, такая стратегия становится неэффективной. В таких случаях муравьиный алгоритм позволяет находить оптимальные маршруты, которые сложно определить вручную.
Практическая ценность работы заключается в демонстрации возможностей алгоритмов, вдохновлённых природой, для решения реальных задач, таких как оптимизация маршрутов в логистике и планировании.
